# Medical Clinic Registration

Веб-сторінка реєстрації пацієнта для медичної клініки.

## Опис проєкту

Форма реєстрації нових пацієнтів з валідацією полів. Призначена для
медичних закладів, які ведуть електронний облік пацієнтів.

## Функціональність

- Введення повного імені пацієнта
- Введення електронної адреси (з валідацією формату)
- Введення номера телефону у форматі +38 (099) 123-45-67
- Вибір дати народження
- Введення та підтвердження паролю
- Кнопка "Замовити пароль"
- Перехід на сторінку входу для існуючих користувачів
